# Night Waves Intelligence R&D v0.4

Adds an isolated Warm Studio Light Find Sound interface.

Implemented:
- local audio file decode
- candidate slice analysis
- visible progress
- cancel control
- Find Sound ranking
- user-triggered audition-only slice preview
- stop preview
- no automatic commit
- no Live Input / recorder / Scenes / DSP hooks

Important:
- Browser UI and acoustic quality have not been human-tested in this environment.
- Preview uses a dedicated AudioBufferSourceNode connected directly to the browser destination for audition only.
- This is not yet wired into production index.html or sampling-workspace.html.
