# Night Waves Unified Studio v1.2

Adds the proven production `index.html` / v2.1 Red Pulse engine as the **Studio** workspace inside the new Night Waves navigation shell.

Architecture:
Track Intelligence → Find Sound → Sound DNA → Studio → Library

Safety decision:
- `index.html` is NOT copied, modified or replaced.
- Studio embeds `./index.html` in an isolated iframe.
- Live Input, recorder, Scenes and DSP remain owned by the existing production page.
- The new shell cannot directly mutate the production audio graph.
- Open full-screen Studio opens the existing production page.
- "Use in Studio" is a navigation handoff at this stage; direct audio/sample transfer is deliberately deferred until an explicit safe message contract is added.

This gives one navigable product while protecting the known working engine.
