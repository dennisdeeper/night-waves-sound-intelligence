# Night Waves Intelligence R&D v0.3

Adds a safe adapter between Track Intelligence recommendations and automatically analysed Sampling slices.

Flow: AudioBuffer -> slice DNA -> candidates -> recommendation intent -> ranked matches -> audition-only preview request.

Safety boundary: this package does not connect to Live Input, recorder, Scenes, DSP graphs, destination output, or automatic audio commit. Preview is a request/event only; the host must explicitly implement audition playback.

Events:
- nw:candidates-ready
- nw:find-sound-request
- nw:find-sound-results
- nw:preview-candidate

Browser/acoustic/live-audio testing has not been performed. Node integration tests cover candidate creation, ranking, safety flags and cancellation before analysis begins.
