# Night Waves Connected Studio v1.3

Purpose: make Find Sound → Studio a real, explicit integration contract without touching the proven v2.1 audio engine.

Meaningful changes:
- Ranked Find Sound rows can select a specific candidate for Studio.
- `nw-studio-handoff.js` creates a strict `nw.studio-handoff/0.1` manifest.
- The manifest contains only sanitized candidate DNA, timing, match reasons/score, and Track Intelligence recommendation metadata.
- Audio buffers, PCM/channel arrays, files/blobs and production AudioNode references are not transported.
- Studio shows the selected-sound handoff tray while continuing to run `./index.html` in an isolated iframe.
- No auto-commit, auto-DSP change, recorder change, Scenes change or audio-graph mutation.

Regression coverage executed in Node:
- malformed recommendation normalization
- confidence clamp/banding
- metadata-only handoff validation
- mono candidate analysis
- progress reaches 100%
- yielding fallback cancellation raises AbortError
- static check: no getUserMedia, MediaRecorder, applyDSP( or connectInput( in shell

Not executed:
- browser rendering
- real Web Worker browser path
- microphone / Live Input
- recorder
- acoustic/listening tests

Next gate:
A tiny receiver adapter can later be added to the Studio host after human regression testing. It should accept only validated handoff metadata first; actual audio transfer should remain a separate explicit capability.
