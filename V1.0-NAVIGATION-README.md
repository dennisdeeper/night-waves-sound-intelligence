# Night Waves v1.0 Navigation Shell

The side menu now works as an app shell rather than linking to unrelated HTML pages.

Views:
- Track Intelligence: track analysis and recommendation
- Find Sound: search, ranked matches and preview
- Sound DNA: analysis descriptors for sounds
- Library: imported/user sound collection
- Settings: appearance and safe preview/commit preferences

Why this structure:
- keeps audio state alive while moving between views
- avoids full-page reloads
- lets Track Intelligence hand recommendations directly to Find Sound
- makes a later real integration with existing modules safer
- production index.html is still untouched

No Live Input / recorder / Scenes / production DSP changes are included.
