# Night Waves Corporate Identity v1.4

## Corporate identity rule
The approved Warm Studio Light NW logo is the single master corporate mark for Night Waves Sound Intelligence.

It is used across:
- Track Intelligence
- Find Sound
- Sound DNA
- Studio
- Library
- Settings
- future R&D/production surfaces that adopt the shared identity layer

Warm Studio and Cyan / Red Pulse may change surrounding interface lighting, but **must not substitute another NW logo**.

## Safety architecture
This build introduces only:
- `night-waves-corporate-logo-warm.png`
- `nw-brand-identity.css`
- `nw-brand-identity.js`
- `connected-studio-v1.4.html`

The existing Live Input, recorder, Scenes, DSP, Track Intelligence behaviour and the production `index.html` are not modified.

The Studio iframe is branded by an external overlay in the shell. The identity script does not reach into or alter the Studio iframe DOM/audio graph.

## Release identity gate
A connected Night Waves interface fails the brand gate if:
1. it does not reference the canonical Warm Studio Light logo;
2. it substitutes a different logo for Pulse mode;
3. it distorts the mark or removes its clear-space treatment;
4. a new app view is not stamped by the shared identity layer.

No browser, microphone, recorder, acoustic or human listening test is claimed by this package.
